# Lumviro domain root

Publishes https://lumviro.github.io/app-ads.txt for the Lumviro AdMob publisher.
The main website remains at https://lumviro.github.io/lumviro-site/.

Only public website infrastructure belongs here. Application source is private.
After changing app-ads.txt, verify HTTP 200 and the publisher entry at the root URL.
AdMob verification additionally requires the store listing's developer website
and linking the store application in AdMob; publication alone is not verification.
